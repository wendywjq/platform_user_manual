说明：画布 - 数据存储

一、背景

在画布类策略部署的时候，存在需要将执行过程中某些关键数据进行外存。

二、名词解释

无

三、操作指南

目前数据存储仅支持squrrile存储（仅支持redis-rc-public_product集群）

说明

页面
  1. 基本信息：名称必填，备注非必填

  2. 配置信息：

    1. 英文名称：支持小些字母、数字和下划线、最多128字符
    2. 数据类型：支持Squrriel、Tair

Squirrel配置

  1. 存储集群：近线默认存储集群为redis-rc-nearline-public_product，若用户存储在自己的集群上，此处请填写数据所存储的集群英文名称

  2. 存储类：为用户在Squirrel上创建的存储名称，若是填写未创建的存储类执行会异常

  3. Squirrel类型：hash/string

  4. 存储类型：

    1. 当选择string时，仅支持获取 key 下单 field 的 value 值

    2. 当选择hash时，可支持获取 key 下单 field 的 value 值/获取 key 下所有 field 值/获取 key 下所有 value 值/获取所有的 k-v 键值对；

  5. key、value、field均可填写表达式，此处若填写常量需要增加引号比如：'a'

  6. 熔断配置：

    1. 时间周期：默认为30分钟，写入量超过500就熔断写入，支持用户自定义时间周期、指标和阈值；
    2. 熔断执行逻辑说明：
    3. 熔断告警人：默认为画布的配置人

Tair配置

  1. 存储集群：近线默认存储集群为com.sankuai.cellar.mtsi.zeusoffline，若用户存储在自己的集群上，此处请填写数据所存储的集群英文名称

  2. area：为用户在Tair上创建的area，若是填写未创建的area执行会异常

  3. Tair类型：hash/string

  4. 存储类型：

    1. 当选择string时，仅支持获取 key 下单 field 的 value 值

    2. 当选择hash时，可支持获取 key 下单 field 的 value 值/获取 key 下所有 field 值/获取 key 下所有 value 值/获取所有的 k-v 键值对；

  5. key、value、field均可填写表达式，此处若填写常量需要增加引号比如：'a'

  6. 熔断配置：

    1. 时间周期：默认为30分钟，写入量超过500就熔断写入，支持用户自定义时间周期、指标和阈值；
    2. 熔断执行逻辑说明：将配置逻辑摊到每分钟，比如上述为每分钟超过16就熔断，则超过部分熔断不写入，会通过错误日志提供出来；
    3. 熔断告警人：默认为画布的配置人
