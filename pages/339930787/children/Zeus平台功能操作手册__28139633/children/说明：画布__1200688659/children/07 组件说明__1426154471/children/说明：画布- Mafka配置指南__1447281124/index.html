说明：画布- Mafka配置指南

一、背景

  • 数据安全、基础安全等相关风险领域需要在近线通过mafka传递日志消息等，当前近线画布缺少mafka消息通道，相关模型诉求无法平滑接入近线

二、名词解释

Mafka：配置Mafka数据源Topic

三、操作指南

说明

页面

【入口】

Zeus-->策略部署-->画布

  1. 左侧为工具栏，涵盖画布配置所需的所有支持的组件；

  2. 将Mafka组件拖拽到画布中央.

  1. 基本信息：确定是哪个mafka topic，并确定消费方式和解析格式

  1. 名称：支持中英文数字等，不超过128字符。填写后画布中央的组件名称会变更，必填

  2. namespace：支持中英文，为topic所在的space组，必填

  3. subscribeGroup：mafka消费组

  4. Topic：指整个画布配置的topic的名称，必填

  5. 消费组appkey

  6. 是否配置set消费：默认不配置set消费

    1. 跨set消费：选中后，将消费所有set
    2. 指定set消费：选中后，需指定一个cell

  7. 消费起点：默认选中从最新消费

    1. 从最新消费
    2. 指定消费起始时间：需选择消费起始的时间，默认回溯一天。如果需要回溯多天消息，请先前往mafka平台申请白名单，若未申请白名单但选择多天，系统将自动只回溯一天消息
    3. 接上次消费

  8. 时间维度：指画布任务执行的时间戳，如果不填topic中的时间字段，则默认系统时间戳，即画布开始运行的时间字段，非必填

  9. 时间维度格式：支持用户对时间维度字段的格式进行转换，如果不填，则默认原格式，非必填

  10. 备注：用户可对该组件进行备注，非必填

  11. 日志类型：即确定所选topic的日志类型，支持Log、NewLog、Snappy，必选

【自定义数据源解析】

选择自定义数据源解析，并在代码块中填写相关解析代码。

代码需要继承IParser抽象类，并实现parse方法：


package com.meituan.rc.zeus.nearline.flink;

import com.google.common.collect.Maps;
import com.meituan.rc.zeus.dynamic.script.runtime.IParser;

import java.util.Map;

public class TestParser implements IParser {
    @Override
    public Map<String, Object> parse(String s) {
        Map<String,Object> map =  Maps.newHashMap();
        map.put("name", 12212);
        return map;
    }
}

如果自定义数据源解析希望输出多条数据，需要继承IFlatParser抽象类，并实现flatParse方法：


package com.meituan.rc.zeus.nearline.flink;

import com.google.common.collect.Maps;
import com.meituan.rc.zeus.dynamic.script.runtime.IFlatParser;

import java.util.Map;

public class TestParser extends IFlatParser {
    @Override
    public List<Map<String, Object>> flatParse(String src) {
        List<Map<String, Object>> ret = new ArrayList<>();
        Map<String,Object> map =  Maps.newHashMap();
        map.put("name", 12212);
        ret.add(map);
        return ret;
    }
}

IParser和IFlatParser所在jar包：


            <dependency>
                <groupId>com.meituan.rc.zeus</groupId>
                <artifactId>zeus-dynamic-script</artifactId>
                <version>1.1.9-nearline</version>
            </dependency>

【参数配置】

  1. 参数配置模块（高级配置）：当用户选择多个kafka 数据源时，可能存在不同数据源有相同的字段，在后面进行逻辑编写时可能存在字段重复导致逻辑配置有问题，所以可以在参数配置模块对topic里的字段进行重命名

    1. 参数名：topic里的字段名

    2. 别名：原topic中的字段名在该画布中的映射，如果进行了参数别名配置，在该画布中编写逻辑时，请直接使用别名

    3. 类型：字段类型

    4. 备注：可对该参数进行备注

    5. 点击右上角「+」号可以新增一个参数配置，也支持删除参数配置
