2、查询结果说明

名称

说明

result

累计因子当前实时累计值

accumulateConfig

累计配置：includeCurrent=1 => 累计自身，includeCurrent=0 => 不累计自身
distinct=1 => 剔除重复项，distinct=0 => 不剔除重复项

accumulateRecords

累计详情，比如说累计值=10，那么这10个都是啥

name

累计字段，即按何累计，比如说按userid累计，此处name=userid

value

累计字段的具体值，比如说按userid累计，此处就是具体userid的值

time

累计时间，此处是一个时间范围：
如果累计周期是分钟，精度为1分钟；
如果累计周期是小时，精度为5分钟；
如果累计周期是日，精度为1小时；

subAccumulateRecord

举例：不剔除重复项时，一个userid对应的累计值可能有多个，此处详细展开每个累计记录
