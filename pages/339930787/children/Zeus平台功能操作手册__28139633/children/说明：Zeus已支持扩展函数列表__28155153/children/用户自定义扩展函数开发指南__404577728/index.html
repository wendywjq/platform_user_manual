用户自定义扩展函数开发指南

用户自定义上传扩展函数会有安全风险问题，目前不支持自动化操作，如有需要请联系zeus值班同学！

背景

内容安全业务存在一些复杂的处理逻辑，当前的表达式语言无法支持规则逻辑配置，通过写java代码来自定义扩展函数，实现最终规则逻辑的配置。

开发方法

  1. 下载demo.zip文件夹

    附件：function-demo.zip（7.32KB；需通过文枢下载）

  2. 解压缩文件到本地，内有一个demo用例MathSqrtFunction，用自己的逻辑替换call()方法的内容，同时修改getName()

    public class MathSqrtFunction extends AbstractFunction {

    /**
     * 核心逻辑
     * @param env  env是系统字段
     * @param arg1 对应表达式中的入参，可支持多个
     * @return AviatorObject，与Java中的类型一一对应
     */
    @Override
    public AviatorObject call(Map<String, Object> env, AviatorObject arg1) {
        /**
         * 如果参数是数字类型，Number num = FunctionUtils.getNumberValue(arg1, env);
         * 如果参数是字符串类型，String str = FunctionUtils.getStringValue(arg1, env);
         */
        Number num = FunctionUtils.getNumberValue(arg1, env);

        return AviatorDouble.valueOf(Math.sqrt(num.doubleValue()));
    }

  	// 根据表达式中入参个数，选择对应的call方法来重写


    @Override
    public AviatorObject call(Map<String, Object> env, AviatorObject arg1, AviatorObject arg2) {
        System.out.println("两个参数场景");
        return null;
    }

    @Override
    public AviatorObject call(Map<String, Object> env, AviatorObject arg1, AviatorObject arg2, AviatorObject arg3) {
        System.out.println("三个参数场景");
        return null;
    }

    @Override
    public AviatorObject call(Map<String, Object> env, AviatorObject arg1, AviatorObject arg2, AviatorObject arg3, AviatorObject arg4) {
        System.out.println("四个参数场景");
        return null;
    }
  
  	// 以此内推，可以支持java上限的参数个数

    /**
     * 返回一个函数名，在表达式中使用
     * math.sqrt(10)
     * @return
     */
    @Override
    public String getName() {
        return "math.sqrt";
    }
}

  3. 表达式用例
math.sqrt(10)

4. 将修改后的文件编译，打包即可。
